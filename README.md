Classic Python Games

A collection of six classic games built using Python and Pygame. These projects explore game development, collision detection, animation, computer opponents, and interactive gameplay.

Games

Game

Description

Pong

Classic table tennis with single-player and two-player modes.

Flappy Bird

Navigate an animated bird through randomly generated pipes.

Dinosaur Dash

An endless runner featuring animated sprites, flying obstacles, and increasing difficulty.

Tic-Tac-Toe

Play against a friend or a computer opponent that makes strategic moves.

Rock Paper Scissors

Compete against the computer in a classic hand game.

Hangman

Guess hidden words of varying difficulty before running out of attempts.

Technologies

Python

Pygame

Python Random and Math libraries

Features

Single-player and multiplayer gameplay

Custom sprite designs and animations

Collision detection and movement physics

Computer-controlled opponents

Randomized obstacles

Score tracking and progressive difficulty

Installation

Download or clone this repository.

Make sure Python 3 is installed.

Install Pygame:

python3 -m pip install pygame

Running the Games

Open a terminal in the project directory and run the desired Python file.

Game

Command

Pong

python3 pong.py

Flappy Bird

python3 flappy_bird.py

Dinosaur Dash

python3 dinosaur.py

Tic-Tac-Toe

python3 tic_tac_toe.py

Rock Paper Scissors

python3 rock_paper_scissors.py
